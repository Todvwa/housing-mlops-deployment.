# Housing Price Prediction - Web Deployment

This repository shows the deployment of a web application for predicting housing prices using a pre-trained machine learning model and Gradio.

## Repository Contents

- 'Housing.csv': The dataset used for training (for reference purposes).
- 'model.pkl': The pre-trained model for predicting housing prices.
- 'app.py': A Gradio-based web application that takes housing inputs and outputs a predicted price.
